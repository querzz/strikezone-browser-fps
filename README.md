# StrikeZone — assistant-authored iteration

This version was written directly by the chat assistant, not taken from the Copilot PR. Original single-player browser FPS prototype; not a finished commercial game.

## Windows launch
Install compatible Node.js LTS (22.12+). Download repository ZIP, extract and double-click start.bat. Internet is needed to install npm dependencies; gameplay has no remote asset dependency. Alternatively: npm install then npm run dev -- --open.

## Implemented
First-person procedural rifle and hands, automatic fire, spread and camera kick, reload, synthesized firing/reload audio, jump/gravity, basic wall collision, humanoid procedural enemies, line-of-sight damage, lighting/shadows, cover, timed elimination rounds and cumulative score.

Controls: WASD movement, mouse view, left mouse automatic fire, R reload, Space jump, Shift sprint, Escape pause. Button resumes or starts next round after win/loss.

## Limits
No multiplayer, allies, weapon shop, weapon switching, bomb mode, advanced pathfinding, imported models or Windows EXE. Bots may get stuck; obstacle bypass is heuristic. Walking meshes are simple stylized geometry. Browser/build execution not verified in the assistant environment. Do not claim this is a complete CS-equivalent game.

All game geometry and oscillator sounds in this version are generated by code; no Counter-Strike assets and no downloaded model license dependencies. Existing Copilot PR remains separate and is not merged by this change.
